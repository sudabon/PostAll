## Requirements
### Requirement: 狭幅での階層ナビゲーション
システムは、ビューポート幅が 768px 未満のとき、3 ペインを同時に並べてはならない (MUST NOT)。チャネル一覧、タイムライン、スレッドをそれぞれ全幅の画面とし、階層的に遷移できなければならない (SHALL)。

#### Scenario: チャネルからタイムラインへ遷移する
- **WHEN** 狭幅画面でユーザーがチャネル一覧のチャネルを選択する
- **THEN** システムはタイムライン画面へ遷移し、選択したチャネル名をヘッダーに表示する

#### Scenario: チャネル一覧へ戻る
- **WHEN** 狭幅のタイムライン画面でユーザーが戻る操作を行う
- **THEN** システムはチャネル一覧へ戻り、直前に選択していたチャネルを強調表示する

#### Scenario: スレッドを開く
- **WHEN** 狭幅のタイムラインでユーザーがスレッドを開く
- **THEN** システムはスレッドを独立した全幅画面として表示し、戻る操作でタイムラインへ復帰する

#### Scenario: 十分な幅では 3 ペインに戻る
- **WHEN** ビューポート幅が 768px 以上になる
- **THEN** システムはチャネルツリーとタイムラインを並列表示する 3 ペインへ切り替え、選択中チャネルと開いているスレッドを維持する

#### Scenario: 起動時に前回のチャネルを開く
- **WHEN** 狭幅で、保存済みの選択チャネルがある状態でアプリを開く
- **THEN** システムはチャネル一覧ではなく、当該チャネルのタイムラインを表示する

### Requirement: システム戻ると履歴スタック
システムは、狭幅での画面遷移をブラウザの履歴スタックへ積まなければならない (SHALL)。広いビューポートでのペイン操作を履歴へ積んではならない (MUST NOT)。

#### Scenario: OS の戻る操作で一つ上の画面へ戻る
- **WHEN** 狭幅でタイムラインまたはスレッドを表示中に、ユーザーがブラウザまたは OS の戻る操作（左端スワイプを含む）を行う
- **THEN** システムは一つ上の画面へ戻り、アプリを閉じたり別サイトへ出たりしない

#### Scenario: アプリ内の戻るボタン
- **WHEN** 狭幅でタイムラインまたはスレッドのヘッダーにある戻るボタンを押す
- **THEN** システムは OS の戻ると同じ一つ上の画面へ戻る

### Requirement: ソフトキーボードと入力フォームの共存
システムは、狭幅において入力フォームを画面最下部に固定し、ソフトキーボード表示時にはフォームがキーボードの上に留まらなければならない (SHALL)。

#### Scenario: キーボードを開く
- **WHEN** 狭幅でユーザーが入力フォームをタップしてソフトキーボードが表示される
- **THEN** システムは入力フォームをキーボードの直上へ移動させ、隠さない

#### Scenario: キーボード表示中もタイムラインを読む
- **WHEN** ソフトキーボードが表示された状態でユーザーがタイムラインをスクロールする
- **THEN** システムはタイムラインをスクロール可能に保ち、入力内容を失わない

#### Scenario: セーフエリアを尊重する
- **WHEN** ノッチやホームインジケータを持つ端末の狭幅画面で表示する
- **THEN** システムはヘッダー・入力フォーム・主要操作をセーフエリア内に配置し、システム UI と重ならない

#### Scenario: 送信の主操作
- **WHEN** 狭幅でユーザーがポストを送信する
- **THEN** システムは送信ボタンを主操作とし、ソフトウェアキーボードの改行キーでは送信しない

### Requirement: タッチでのチャネル階層編集
システムは、狭幅においてもチャネル階層の展開・折りたたみ、および並び替えができなければならない (SHALL)。通常の縦スクロールをドラッグ開始と誤認してはならない (MUST NOT)。

#### Scenario: 階層を展開する
- **WHEN** ユーザーが子を持つチャネル行の展開トグルをタップする
- **THEN** システムは子チャネルの表示を切り替える

#### Scenario: 長押し後にドラッグして移動する
- **WHEN** 狭幅でユーザーがチャネル行を長押ししてからドラッグし、別の位置でドロップする
- **THEN** システムは親の付け替えまたは並び順の変更を適用する

#### Scenario: スクロールとドラッグを取り違えない
- **WHEN** 狭幅のチャネル一覧をユーザーがすぐに指で縦に動かす
- **THEN** システムは一覧をスクロールし、チャネルの移動を開始しない
