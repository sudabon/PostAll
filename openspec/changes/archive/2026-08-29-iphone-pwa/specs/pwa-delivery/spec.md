## MODIFIED Requirements

### Requirement: ブラウザからの利用
システムは、Electron デスクトップアプリと同一のフロントエンドを、ブラウザからも利用できる形で配信しなければならない (SHALL)。ブラウザで利用する場合も、チャネル・タイムライン・投稿・スレッド・リアクション・検索の各機能が利用できなければならない (SHALL)。

#### Scenario: ブラウザで開く
- **WHEN** ユーザーが対応ブラウザでアプリの URL を開く
- **THEN** システムはビューポート幅に応じたシェル（十分な幅では 3 ペイン、768px 未満では `web-narrow-shell` の階層画面）を表示し、サインイン後にチャネルとタイムラインを操作できるようにする

#### Scenario: 同一の成果物を配信する
- **WHEN** フロントエンドをビルドする
- **THEN** システムは Electron に同梱する成果物と PWA として配信する成果物を、同一のソースから生成する

#### Scenario: iPhone の Safari で開く
- **WHEN** ユーザーが iPhone の Safari でアプリの URL を開く
- **THEN** システムは狭幅シェルを表示し、横スクロールを強制する最小幅を課さない

### Requirement: インストール可能な PWA
システムは、ブラウザからホーム画面またはアプリケーションとしてインストールできる PWA として構成されなければならない (SHALL)。iOS Safari の「ホーム画面に追加」を含まなければならない (SHALL)。

#### Scenario: インストールを提示する
- **WHEN** インストール要件を満たすブラウザでアプリを開く
- **THEN** システムはインストール可能であることをブラウザが提示できる状態（マニフェストとアイコンが揃った状態）で配信する

#### Scenario: インストール後に起動する
- **WHEN** ユーザーがインストール済みの PWA を起動する
- **THEN** システムはブラウザの UI を伴わない独立ウィンドウとして表示し、アプリ名とアイコンを反映する

#### Scenario: iOS のホーム画面に追加する
- **WHEN** ユーザーが iOS Safari の共有メニューからアプリをホーム画面に追加する
- **THEN** システムはスタンドアロン表示に必要なメタデータ（Web App Manifest、apple-mobile-web-app 系メタ、apple-touch-icon）を提供し、追加したアイコンからブラウザクローム無しで起動できる

## ADDED Requirements

### Requirement: スタンドアロンでのサインイン導線
システムは、iOS のスタンドアロン PWA と Safari タブでストレージが隔離されることを前提に、今開いているコンテキストの中でサインインを完了させなければならない (SHALL)。

#### Scenario: スタンドアロン内で認可へ進む
- **WHEN** ホーム画面から起動した PWA でユーザーがサインインを開始する
- **THEN** システムは同一ドキュメントの遷移で認可 URL へ進み、別ウィンドウやカスタム URL スキームへ切り替えない

#### Scenario: ストレージ隔離をサインイン前に伝える
- **WHEN** ホーム画面から起動した未サインインの PWA がサインイン画面を表示する
- **THEN** システムは、認可の途中で別のブラウザが開いた場合はそちらで使い続けるか、ホーム画面アプリに戻って再度サインインする旨を示す
