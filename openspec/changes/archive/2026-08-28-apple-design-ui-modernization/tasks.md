## 3. 操作プリミティブの実装

- [x] 3.1 `usePressable()` を実装する。pointer-down で押下状態を立て、範囲外への離脱で解除、範囲内への復帰で再度立て、pointer-up で確定する。約 10px のヒットパディングを含める
- [x] 3.2 `usePressable()` の単体テストを書く（押下即時反映 / 範囲外で解除 / 復帰して確定 / 範囲外解放では確定しない）
- [x] 3.3 ジェスチャの純粋関数を `src/lib/motion/gesture.ts` に実装する。解放速度の算出（直近数フレームの位置と時刻）、停止位置の予測 `current + (v/1000) * d / (1 - d)`（`d = 0.998`）、ラバーバンディング `overshoot * dim * c / (dim + c * |overshoot|)`（`c = 0.55`）
- [x] 3.4 `gesture.ts` の単体テストを書く（速度算出 / 速い解放ほど遠くへ着地 / 境界超過で減衰 / 境界内では減衰なし）
- [x] 3.5 `useDragValue()` を実装する。`setPointerCapture` による追従、グラブオフセットの保持、移動閾値を超えるまで方向を確定しない、境界外はラバーバンディング、解放時は予測停止位置から吸着先を選び `momentum` プリセットへ速度を引き継ぐ
- [x] 3.6 `useDragValue()` の単体テストを書く（オフセット保持 / 範囲外でも追従継続 / 閾値前は方向未確定 / 解放時に速度が渡る）
- [x] 3.7 `useOverlayPresence()` を実装する。`<dialog>` の `showModal()` と `AnimatePresence` を橋渡しし、退出完了後に `close()` を呼ぶ。閉じる途中の再オープンで `close()` が呼ばれないことを保証する
- [x] 3.8 `useReducedMotion()` を参照し、移動・拡大を伴う演出を短いクロスフェードへ差し替える分岐を各プリミティブへ組み込む
